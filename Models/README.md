Model location: `iml_rev.py` and `iml_rev_ishapley.py` read the per-period model files from the environment
variable `IML_MODELS_DIR` (default `../../Models` relative to `Code/V002`, i.e. this folder), under
`<IML_MODELS_DIR>/20241005_091334/cpiaucsl_h<h>/`. Set it if the archive is extracted elsewhere:

    IML_MODELS_DIR=/data/models poetry run python -c "import iml_rev; ..."        # Linux/macOS
    $env:IML_MODELS_DIR = 'D:\models'                                             # Windows PowerShell

The monolithic `cpiaucsl_h<h>.bin` files read by `iml_rev.get_ys()` are not in the archive (only the split
per-period files are); `ys_upd.bin`, the output of `get_ys()`, is in the repository. Tier 2 also needs
`tensorflow==2.5.0` and `shap==0.42.1` (README, Section 9).
